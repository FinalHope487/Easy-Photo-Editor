# 升級舊版 kit：要改掉的舊措辭

步驟 1b 用。專案已經有舊版 `CLAUDE.md` 章節時逐條檢查。已存在的章節不覆蓋，
但下面這些會與新加的章節直接打架，逐條改掉：

| 位置 | 舊 | 改成 |
|---|---|---|
| `# 決策分級` 末尾引言 | 「一律視為高風險，**停下來問**」 | 換成 `assets/claude-md-rules.md` 目前版本的引言 |
| `# 決策分級` 高風險「改 schema」 | 只有一行「改 schema / 建 migration / db push」，或有「改讀寫函式就等於改 schema」這句與判準並列 | **換成規則全文的三段式判定** |
| `# 提問機制`「怎麼問」第 4 條 | 「**問完就停**」 | 「**不要停下來等**」那一整條 |
| `# 提問機制` | 沒有「開工前先列設計軸」那一步 | 補上 |
| `# 驗證：不接受目測` 規則 | 只有「改動前是紅的」 | 補「**紅的理由必須是你要測的那件事**」與它的分辨方法 |
| `# 長時工作模式` | 章節名 | 改名 `# 工作模式` |
| 「修 3 **輪**仍紅」 | | 「修 3 **次**仍紅」——〈工作模式〉開頭已定義「輪」＝一次委派、「次」＝輪內重試 |
| `# Git Commit 規範`（若獨立成節） | 整節 | 併入〈留痕與收尾〉的「怎麼 commit」，刪掉獨立章節 |
